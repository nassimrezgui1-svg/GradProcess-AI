# GradProcess AI — Setup Guide

## 1. Prerequisites

- Node.js 18+ (LTS recommended)
- npm or pnpm
- A Supabase account (free tier works)
- An OpenAI API key

---

## 2. Install dependencies

```bash
npm install
```

---

## 3. Environment variables

Copy `.env.example` to `.env.local`:

```bash
cp .env.example .env.local
```

Fill in your values:
- `NEXT_PUBLIC_SUPABASE_URL` — from Supabase Dashboard > Settings > API
- `NEXT_PUBLIC_SUPABASE_ANON_KEY` — from Supabase Dashboard > Settings > API
- `SUPABASE_SERVICE_ROLE_KEY` — from Supabase Dashboard > Settings > API (⚠️ keep secret)
- `OPENAI_API_KEY` — from platform.openai.com

---

## 4. Supabase setup

### 4a. Create a Supabase project
1. Go to [supabase.com](https://supabase.com) and create a new project
2. Choose your region (EU West recommended for GDPR)
3. Copy your URL and API keys to `.env.local`

### 4b. Run the database schema
1. Open Supabase Dashboard > SQL Editor > New Query
2. Paste and run the full contents of `supabase/schema.sql`

### 4c. Create storage buckets
In Supabase Dashboard > Storage, create these **private** buckets:
- `cv_uploads` (max 10MB)
- `interview_videos` (max 500MB)
- `interview_audio` (max 100MB)
- `profile_images` (max 5MB)
- `exported_reports` (max 50MB)

### 4d. Enable Email Auth
In Supabase Dashboard > Authentication > Providers:
- Enable Email provider
- Enable "Confirm email" 
- Set your Site URL to `http://localhost:3000` for local dev

---

## 8. Security checklist

- [ ] All Supabase tables have RLS enabled
- [ ] Storage buckets are private (no public URLs)
- [ ] `SUPABASE_SERVICE_ROLE_KEY` is never exposed client-side
- [ ] OPENAI_API_KEY is never exposed client-side
- [ ] `.env.local` is in `.gitignore`
- [ ] Email verification is enabled in Supabase Auth
- [ ] Content Security Policy headers configured in production

## Stripe Integration (added)

### Required Environment Variables

```env
NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY=pk_live_...
STRIPE_SECRET_KEY=sk_live_...
STRIPE_WEBHOOK_SECRET=whsec_...
STRIPE_STUDENT_PRO_PRICE_ID=price_...
NEXT_PUBLIC_APP_URL=https://your-domain.com
SUPABASE_SERVICE_ROLE_KEY=eyJ...
```

### Stripe Dashboard Setup

1. Create Product: **"GradProcess AI — Student Pro"**, Price: **£19.99/month recurring**
2. Copy the `price_...` ID → `STRIPE_STUDENT_PRO_PRICE_ID`
3. Configure **Customer Portal**: `dashboard.stripe.com/settings/billing/portal`
   - Enable: cancel subscription, update payment method, view invoices
4. Add Webhook endpoint: `https://your-domain.com/api/stripe/webhook`
   - Events: `customer.subscription.created`, `customer.subscription.updated`, `customer.subscription.deleted`, `invoice.payment_failed`, `invoice.payment_succeeded`
5. Copy webhook signing secret → `STRIPE_WEBHOOK_SECRET`

### Subscription Gate Flow

- Protected routes require auth + `subscriptions.status IN ('active','trialing')`
- No subscription → redirected to `/pricing?gate=1`
- Not logged in → redirected to `/login?next=<path>`
- `/billing` page is accessible with auth only (to subscribe or manage)
